## How it works

- Each flow has a root page (`flows/<flow>/index.mdx`) with its goal, entry and product summary.
- Each screen has a `.periplus.ts` **next to its code** (typed by the flow) with rules, APIs and links to neighboring screens.
- `periplus build` merges everything into a graph; these pages and the interactive maps are generated from it.
- CI warns when a screen's code changes and its doc has not been reviewed.
